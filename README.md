# AMB BOUTIQUE

International women’s fashion storefront based in San Diego, California and founded by Ana Paula Maciel.

## Markets

- United States — USD
- Canada — CAD
- United Kingdom — GBP
- Australia — AUD
- New Zealand — NZD

## Development

```bash
npm install
npm run dev
```

The initial phase includes the responsive homepage, filtered collection page, reusable product detail template and interactive cart drawer. Real product data, inventory, payment processing and policy flows will be connected in the next phases.

Deployment is intentionally deferred until explicit approval.

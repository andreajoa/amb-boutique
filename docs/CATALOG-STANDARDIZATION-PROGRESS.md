## Validation gates for every remaining base

1. Match source using variant colours, sizes, stock, weight and visual confirmation.
2. Confirm the true garment category before generating images.
3. Generate or recover the four required views from supplier references.
4. Check garment construction, colour, model consistency, framing and background.
5. Export four 1600 × 1600 WebP files.
6. Update gallery references, name, category and source-faithful copy.
7. Run the production build and visual review before publication.

No incomplete gallery should be released to production.
